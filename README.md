# CloudLedger ☁️📊

> **AWS Student Cloud Usage & Cost Monitoring System**  
> An administrator-only FinOps and governance platform designed to track, attribute, and monitor AWS cloud resource usage and expenditure across student IAM accounts.

---

## 🎯 Executive Summary
In educational and laboratory environments, students are provisioned individual IAM users or roles within a shared AWS account. Because AWS Billing does not natively map financial charges to IAM identities, institutions face runaway cloud bills, untagged orphan resources, and zero visibility into individual student consumption.

**CloudLedger** solves this problem by fusing real-time **AWS CloudTrail** management events, automated **AWS Resource Discovery**, and **AWS Cost Explorer / CUR 2.0** billing exports through a **4-tier cost attribution engine**.

---

## 🏗️ Architecture & Technical Stack

- **Frontend:** React 18, TypeScript, Tailwind CSS, Recharts, Lucide Icons
- **Backend:** Python FastAPI, Pydantic v2, SQLAlchemy 2.0 (Async), Boto3
- **Database:** PostgreSQL 16 (UUIDs, partitioned event tables, JSONB tagging)
- **Infrastructure as Code:** Terraform
- **CI/CD:** GitHub Actions (Ruff, Pytest with Moto AWS mocks, ESLint, Trivy security scan)
- **Security:** Read-only least-privilege IAM policies, private RDS, JWT authentication

## 🚀 Key System Features

1. **4-Tier Cost Attribution Engine:**
   - **Tier 1 (100%):** Direct Cost Allocation Tag match (`Owner: <student_username>`).
   - **Tier 2 (95%):** CloudTrail Event Provenance (`ResourceId` matched to resource creation identity).
   - **Tier 3 (65%):** Time-Window Pro-Rata attribution for shared regional services (flagged as estimated).
   - **Tier 4 (N/A):** Unallocated Account Overhead Pool (NAT Gateways, Support, Tax).
2. **FinOps Executive Dashboard:**
   - Real-time spend vs budget caps, cost forecast, and 30-day burn rate.
   - Attributed vs Unallocated expenditure distribution.
3. **Student Roster & Budget Caps:**
   - Student-by-student cloud balance sheet, active resource inventory, and warning thresholds (80% warning, 100% alert).
4. **Resource Governance & Tag Auditor:**
   - Discovered AWS resources (EC2, S3, RDS, Lambda, SageMaker) with tag compliance indicators and 1-click ownership reassignment.
5. **Cost-Frugal Engineering:**
   - Caches AWS Cost Explorer API responses ($0.01 per query) to avoid unnecessary cloud bills generated by the monitoring system itself.
